# 📱 Platform Exam App

A modern **Flutter-based exam platform** designed to manage and take exams بسهولة وبشكل منظم.  
The app supports both **users** and **admins**, providing a complete exam experience with real-time data handling.

---

## 🚀 Features

### 👤 User Features
- 🔐 Authentication (Email & Google Sign-In)
- 📝 Take Exams بسهولة
- ⛔ Prevent retaking exams after submission
- 📊 View leaderboard (Top Scores)
- ❤️ Like and interact with posts
- 👤 Manage personal profile

### 🛠️ Admin Features
- ➕ Add new exams
- ❌ Delete exams
- 📢 Create posts and announcements
- 👀 Manage exam content
